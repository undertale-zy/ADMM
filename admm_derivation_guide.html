为什么要最小化这个目标函数，X、B、V、D 又分别是什么？

这份说明从雷达实际测到的回波开始，先说明为什么图像不能直接反算，再构造稀疏目标函数， 最后逐行推导 ADMM 更新以及作者如何消掉巨型矩阵求逆。

先回答“求什么” X̂ 是真实目标图像的估计，不是另一个观测量。
再回答“为什么这样求” 测量不足且含噪声，需要同时满足数据一致性和稀疏性。
最后回答“怎样算” ADMM 用 X、B、V 分工，再利用傅里叶结构加速。
已知与未知 为何不能直接求 目标函数 为什么引入 B、V x 更新从哪里来 D 与求逆化简 完整迭代 逻辑总链
01

第一步：先分清已知量和未知量

雷达直接获得的是回波矩阵 S，而不是飞机图像。ISAR 成像的任务，是根据回波反推出目标在二维平面上的反射强度。

S = Fa · Xtrue · FrT + Z 正向模型：如果真实图像已知，它会怎样产生雷达观测
S
已观测雷达实际测到的二维复数回波矩阵。
Xtrue
真实但未知现实中存在的目标反射率图像。
Fa
已知算子描述方位方向如何从图像变成回波。
Fr
已知算子描述距离方向如何从图像变成回波。
Z
噪声接收机噪声以及没有被模型解释的误差。
T
运算符右上角 T 表示矩阵转置。
成像就是一个反问题。

已知 S、Fa、Fr，希望反过来估计不知道的 Xtrue。

02

第二步：为什么不能直接反算 X

如果没有噪声，而且两个傅里叶矩阵都是可逆方阵，理论上可以左右乘逆矩阵得到 X。 但论文为了获得超分辨率图像，故意让待恢复像素数多于实际测量数。

Yak-42 回波测量数 16,384 S 的大小为 256 × 64
待恢复图像像素数 65,536 X 的大小为 512 × 128

未知数比测量值多四倍，因此很多不同图像都可能产生相似的回波。再加上噪声 Z，严格要求 S = FaXFrT 也不合理。

测量给出的条件 候选图像产生的回波应当接近真实回波。
+
目标结构给出的条件 飞机通常只在少量位置产生强散射，因此图像应当稀疏。
→
可选择的解 在许多能解释回波的图像中，选择更符合稀疏结构的一张。
稀疏性不是算法凭空制造的信息。

它是作者加入的先验假设：目标在选定像素网格上只有少数显著反射点。若真实场景并不稀疏，这个假设就可能损失细节。

03

第三步：两个要求怎样组成目标函数

要求一：候选图像要能解释回波

先随便提出一张候选图像 X。它预测出的回波是：

Spredict = Fa · X · FrT X 在这里是优化过程正在尝试的候选图像

真实回波减去预测回波，得到残差矩阵：

R = S − Fa · X · FrT R 越小，候选图像越能解释真实测量

把残差矩阵中每个元素的幅度平方后相加，就得到一个总误差。Frobenius 范数的平方 ‖R‖F2 正是这个含义：

数据代价 = ½ ‖S − Fa · X · FrT‖F2 前面的 ½ 方便求导，不改变最佳图像的位置

要求二：候选图像要尽量稀疏

‖X‖1 表示 X 中所有像素幅度之和。让它变小，会推动大量较小像素变成零：

稀疏代价 = λ ‖X‖1 = λ · Σi,j |Xi,j| λ 控制稀疏要求在总目标中的分量
λ 的大小更重视什么可能结果
较小拟合回波保留更多弱细节，也可能保留更多噪声。
适中在两者间平衡保留主要散射结构并抑制背景。
较大图像稀疏背景更干净，但真实弱散射点也可能被删除。

把两个要求合在一起

X̂ = arg minX [ ½‖S − Fa · X · FrT‖F2 + λ‖X‖1 ] 在所有候选 X 中，寻找“回波误差 + 稀疏代价”最小的那一张
符号身份准确含义
Xtrue真实但未知现实中存在、算法无法直接看到的目标图像。
X候选变量优化过程中被反复尝试和调整的图像。
X̂估计结果使目标函数最小的候选图像，用来估计 Xtrue。
arg min选择操作返回“让后面表达式最小的 X”，不是返回最小代价值本身。
这就是为什么要求这个目标函数。

测量不足使回波拟合条件不能唯一确定图像，所以再加入稀疏先验，从许多可能解中选择既符合回波、又更像稀疏 ISAR 场景的一张。

04

第四步：为什么引入 B 和 V

数据误差是平滑的平方函数，而 ‖X‖1 含有绝对值，在零点不可微。 同一个 X 同时承担两种性质不同的任务，使直接求解不方便。

ADMM 的基本办法：复制一个变量，拆开两项。

让 X 负责拟合回波，让辅助变量 B 负责稀疏化，再要求它们最终相等。

最小化：½‖S − Fa · X · FrT‖F2 + λ‖B‖1 约束：X = B 因为最终强制 X 与 B 相等，所以这和原目标函数等价
X 主要变量 负责数据一致性：生成的回波应接近真实 S。
B 辅助变量 X 的计算副本，负责接受 L1 软阈值稀疏化。
V 缩放对偶变量 累计 X 与 B 的分歧，推动两者逐轮一致。
D 临时简称 D = B − V，只用于缩短 X 更新公式，没有独立物理意义。

V 的更新最能说明它的作用：

V(k+1) = V(k) + X(k+1) − B(k+1) 把本轮 X 与 B 的差异累加进去，下一轮继续纠正

k 表示当前迭代编号。若某个位置上 X 长期大于 B，对应的 V 会不断积累差异，并在后续更新中影响两者。 因此 V 可以直观地理解为“不一致的记忆器”。

05

第五步：x(k+1) 的求逆公式从哪里来

先解释为什么突然出现小写字母

为了推导，论文暂时把每个二维矩阵逐列堆成一个长向量：

x = vec(X)，b = vec(B)，v = vec(V)，s = vec(S) Φ = Fr ⊗ Fa ⊗ 表示 Kronecker 积；大小写只是矩阵形式与向量形式的区别

二维与一维形式完全等价，因为：

vec(Fa · X · FrT) = (Fr ⊗ Fa) · vec(X) 因此二维观测模型可写成 s = Φx + z，没有丢失或新增信息

在第 k 轮，只更新 x

此时 b(k) 和 v(k) 暂时固定，只寻找新的 x。ADMM 给出的 x 子问题是：

x(k+1) = arg minx [ ½‖s − Φx‖22 + δ/2 · ‖x − b(k) + v(k)‖22 ] 第一项要求符合回波，第二项要求 x 靠近当前辅助结果；δ 控制 ADMM 内部靠拢力度
不要混淆 λ 和 δ。

λ 决定最终目标里稀疏性有多重要；δ 是 ADMM 的惩罚参数，主要影响 X 和 B 在迭代中怎样靠拢及收敛速度。

逐行求出这个子问题的答案

1. 对第一项求导

回波平方误差关于 x 的导数是：

ΦH(Φx − s)
2. 对第二项求导

一致性平方项关于 x 的导数是：

δ[x − b(k) + v(k)]
3. 最小点的总导数等于零
ΦH(Φx − s) + δ[x − b(k) + v(k)] = 0
4. 展开并把含 x 的项放在左侧
(ΦHΦ + δI)x = ΦHs + δ[b(k) − v(k)]
5. 解这个线性方程
x(k+1) = (ΦHΦ + δI)−1 · [ΦHs + δ(b(k) − v(k))]
符号含义
H共轭转置。ΦH 可以把测量空间中的量反投影到图像空间。
I单位矩阵。
−1矩阵逆，用来解上面的线性方程。
x(k+1)第 k+1 轮新得到的数据一致性图像向量。
这个求逆公式不是新的总目标。

它只是第 k 轮中，在 b(k)、v(k) 已知时，x 子问题的解析答案。

06

第六步：D 是什么，为什么能消掉大矩阵求逆

D 只是反复出现部分的简称

因为 b(k) − v(k) 总是一起出现，先定义：

d(k) = b(k) − v(k) 恢复成二维矩阵后就是 D(k) = B(k) − V(k)

D 可以理解为“上一轮稀疏结果 B 扣除累计分歧 V 后，本轮 X 更新使用的参考图像”。 但它只是临时计算量，不是第五种物理对象。

真正困难的是巨型矩阵逆

Φ = Fr ⊗ Fa 非常大。Yak-42 设置下，仅显式保存 Φ 就约需 16 GiB， 更不用说计算 (ΦHΦ + δI)−1。

显式 Kronecker 字典 Φ 约 16 GiB 16,384 × 65,536 个复双精度元素
分别保存 Fa 与 Fr 约 2.13 MiB 保留二维可分离结构

能够化简的关键条件

归一化部分傅里叶矩阵的行互相正交：

FaFaH = I FrFrH = I 所以 ΦΦH = I 这是后续 Woodbury 化简成立的前提，不适用于任意观测矩阵

利用这个正交性质和 Woodbury 矩阵恒等式，原求逆形式可严格改写成：

x(k+1) = d(k) − 1/(1+δ) · ΦH[Φd(k) − s] 这是等价变换，不是近似迭代
  1. 用参考图像预测回波

    Φd(k) 是 d(k) 按观测模型生成的预测测量。

  2. 计算测量残差

    Φd(k) − s 表示预测回波与真实回波的差异。

  3. 把残差反投影到图像空间

    ΦH[Φd(k) − s] 告诉算法图像应向哪个方向修正。

  4. 修正当前参考图像

    从 d(k) 中减去按 1/(1+δ) 缩放后的反投影残差。

最后恢复成二维矩阵形式

D(k) = B(k) − V(k) X(k+1) = D(k) − 1/(1+δ) · FaH · [Fa · D(k) · FrT − S] · Fr* 右上角 * 表示逐元素复共轭；方括号内是二维回波残差
作者在这里真正替换了什么？

把“显式构造 Φ 并做大矩阵求逆”，换成“保留二维结构，预测回波、计算残差、再把残差反投影”。规则傅里叶结构下还可继续把矩阵乘法换成 FFT/IFFT。

07

第七步：得到 X 后，B 和 V 怎样更新

X(k+1) 主要负责解释测量，还不一定足够稀疏。因此下一步把 X(k+1) + V(k) 交给软阈值：

B(k+1) = soft[X(k+1) + V(k), λ/δ] B 是经过稀疏处理的辅助图像
单个复数像素 z软阈值结果作用
|z| ≤ λ/δ变成 0删除幅度较小、不够可信的像素。
|z| > λ/δ保留相位，幅度减小 λ/δ保留较强散射点，同时施加稀疏收缩。

接着累计本轮 X 与 B 的分歧：

V(k+1) = V(k) + X(k+1) − B(k+1) V 把尚未满足 X = B 的部分带入下一轮

一轮 ADMM 的完整执行顺序

01
组合参考图像D(k) = B(k) − V(k)
把稀疏结果和累计修正合成 X 更新的起点。
02
更新 X预测回波并反投影残差
让图像更符合真实测量 S。
03
更新 B执行复数软阈值
把大量小像素压成零，使图像稀疏。
04
更新 V累加 X − B
推动数据解和稀疏解逐渐一致。
05
检查停止比较相邻两轮 X
变化足够小或达到最大迭代次数时停止。

理想收敛时，X 与 B 接近相等：X 既能解释雷达回波，也已经是稀疏图像。最终返回的 X 就是估计结果 X̂。

08

最后把整条逻辑连起来

  1. 真实图像未知

    现实中存在 Xtrue，但雷达只能测到回波 S。

  2. 反问题不唯一

    待恢复像素多于测量值，而且回波含噪声，不能直接求逆。

  3. 加入稀疏先验

    飞机只有少量强散射位置，从许多可能解中偏好稀疏图像。

  4. 构造总目标

    同时最小化回波拟合误差和 L1 稀疏代价，最优候选图像记作 X̂。

  5. 拆分两个不同性质的项

    X 负责数据拟合，辅助副本 B 负责稀疏，并要求 X = B。

  6. 用 V 协调一致性

    V 累计 X 与 B 的差异，使它们在迭代中逐渐相等。

  7. 推导 X 子问题

    固定 b、v 后对平方目标求导，得到包含大矩阵逆的解析答案。

  8. 利用傅里叶行正交

    结合 Woodbury 恒等式，把大矩阵求逆换成残差反投影。

  9. 恢复二维并用 FFT 加速

    避免 Kronecker 大字典，分别处理距离和方位两个方向。

  10. 迭代得到 X̂

    交替执行数据修正、软阈值和分歧累计，直到停止。

一句话总结

X̂ 是算法对真实 ISAR 图像的估计；目标函数之所以同时包含回波误差和 L1 范数，是因为有限含噪测量不能唯一确定图像，必须利用散射点稀疏这一先验； ADMM 再用 X、B、V 分别承担数据拟合、稀疏化和一致性协调，D 只是 B − V 的临时简称，最后利用傅里叶正交性把昂贵的大矩阵求逆变成二维残差反投影。
