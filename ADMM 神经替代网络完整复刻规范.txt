ADMM 神经替代网络完整复刻规范

本文档是当前 ADMM 神经替代项目的网络结构、物理 forward、训练、数据集、评测和迭代历史复刻规范。

目标是：即使另一个对话无法访问当前代码，也可以根据本文档重新实现行为等价的网络。

本文档不包含模型 checkpoint，因此可以复刻网络结构、forward、loss、训练流程和实验策略，但不能保证在没有 checkpoint 的情况下得到逐参数相同的结果。

0. 版本和复刻边界

当前项目 Git 历史的两个关键版本：

1初始神经展开基线：2ec77a0
2当前迭代版本： 6b8c629

2ec77a0 代表最初的 Stage 1、Stage 2、Stage 3 网络；6b8c629 代表加入 support fusion、Stage-1 guide、structured/dense 数据集和 Round 32–36 后的版本。

本文档中的“一模一样”分为三层：

结构级一致

在没有原代码的情况下，应当可以重建：

类和模块层级；

输入输出张量形状；

FFT forward/adjoint；

ADMM 每层更新；

CNN/Transformer 结构；

support mask 和物理 data consistency；

数据生成规则；

loss、optimizer、训练参数和 checkpoint 选择。

权重级一致

若没有原始 checkpoint，无法保证 raw_c/raw_tau/raw_beta、CNN 权重或 Transformer 权重逐参数一致。

输出级一致

若没有同时提供 checkpoint、数据、随机种子、PyTorch/CUDA 版本和 FFT 数值环境，不能保证逐像素输出完全一致。

因此本文档的目标是：

让另一个对话重新写出与当前版本结构、forward、训练行为和评测逻辑一致的网络。

1. 任务和物理模型

1.1 ISAR 图像和测量

目标图像是二维复数反射率矩阵：

1X ∈ C^(P×Q)

观测 echo 是二维复数测量矩阵：

1S ∈ C^(M×N)

默认尺寸：

1image_shape = (512, 128)
2measurement_shape = (256, 64)

默认输入到 PyTorch 网络时，不直接使用 complex tensor，而使用两个实数通道：

1measurements.shape = [B, 2, 256, 64]
2target.shape = [B, 2, 512, 128]

通道含义：

1channel 0 = real part
2channel 1 = imaginary part

1.2 复数转换

从两个实通道转为复数：

1z = real + 1j * imag

数学形式：

1complex_from_channels([real, imag]) = real + i·imag

复数转回两个通道：

1complex_to_channels(z) = [real(z), imag(z)]

FFT 和复数 soft-threshold 使用 complex64/complex128；CNN 和 Transformer 在 real/imag 两通道上工作。

1.3 Forward operator

当前使用归一化的部分二维 Fourier forward operator，记为 A(X)。

对图像 X 执行：

11. 在 range 维做 ifft，长度 P=512，并乘 sqrt(P)；
22. 保留 range 维前 M=256 个 bin；
33. 在 azimuth/Doppler 维做 fft，长度 Q=128，并除 sqrt(Q)；
44. 保留 Doppler 维前 N=64 个 bin。

伪代码：

1range_domain = ifft(X, n=P, dim=-2) * sqrt(P)
2range_domain = range_domain[..., :M, :]
3echo = fft(range_domain, n=Q, dim=-1) / sqrt(Q)
4echo = echo[..., :, :N]

因此：

1A: C^(512×128) → C^(256×64)

1.4 Adjoint operator

记 Aᴴ 为 forward operator 的伴随操作。

伪代码：

1image = fft(S, n=P, dim=-2) / sqrt(P)
2image = ifft(image, n=Q, dim=-1) * sqrt(Q)

其中 S 的空间形状是 (M,N)，输出形状是 (P,Q)。

1.5 复数 soft-threshold

对每个复数像素 z，阈值为非负实数 τ：

1soft(z, τ) = z · max(|z|-τ, 0) / (|z|+ε)

其中：

1ε = 1e-12

这个定义保持复数相位，只压缩幅度。

2. 最基础网络：Stage 1 Scalar-8

Stage 1 是整个项目最重要的基础网络。

它不是普通 image-to-image CNN，而是将传统 ADMM 的 8 次迭代展开成 8 层，每层只学习 3 个 scalar。

2.1 状态变量

每一层维护：

1X_k：当前图像/data-consistency 状态
2Z_k：稀疏辅助变量
3U_k：scaled dual variable

初始状态：

1observed = complex_from_channels(measurements)
2image = Aᴴ(observed)
3sparse_image = zeros_like(image)
4scaled_dual = zeros_like(image)

2.2 每层 ADMM 更新

对第 k 层：

1D_k = Z_k - U_k
2R_k = A(D_k) - S
3
4X_(k+1) = D_k - c_k · Aᴴ(R_k)
5
6Z_(k+1) = soft(X_(k+1) + U_k, τ_k)
7
8U_(k+1) = U_k + β_k · (X_(k+1) - Z_(k+1))

伪代码：

1for k in range(8):
2 difference = sparse_image - scaled_dual
3 residual = A(difference) - observed
4
5 next_image = difference - c[k] * A_adjoint(residual)
6 next_sparse = complex_soft_threshold(next_image + scaled_dual, tau[k])
7
8 next_dual = scaled_dual + beta[k] * (next_image - next_sparse)
9
10 image = next_image
11 sparse_image = next_sparse
12 scaled_dual = next_dual

网络最终返回：

1complex_to_channels(image)

当前实现返回 X 状态，而不是再次硬阈值后的 Z。

2.3 可学习参数

每层 3 个正参数：

1c_k
2τ_k
3β_k

共：

18 × 3 = 24 个核心 scalar

为了保证参数为正，实际保存 raw 参数：

1c[k] = softplus(raw_c[k])
2tau[k] = softplus(raw_tau[k])
3beta[k] = softplus(raw_beta[k])

初始化：

1c_k = 0.5
2τ_k = 0.0065
3β_k = 1.0

若需要反向初始化 raw，使用 inverse softplus：

1inverse_softplus(v) = v + log(1 - exp(-v))

2.4 Stage 1 参数和训练

默认配置：

1image_shape = (512,128)
2measurement_shape = (256,64)
3num_layers = 8
4proximal = none
5train_samples = 20000
6validation_samples= 1000
7test_samples = 1000
8batch_size = 2
9epochs = 100
10learning_rate = 1e-3

Stage 1 的核心训练 loss：

1image NMSE
2+ 0.1 × observed echo NMSE
3+ 0.0001 × sparsity penalty

其中 sparsity penalty 不是对 ADMM 的 Z 状态，也不是逐样本归一化 L1；它直接作用于网络最终返回的复数图像 X_pred：

1predicted_image = complex_from_channels(prediction) # [B,P,Q]
2L_sparse = torch.mean(torch.abs(predicted_image))

torch.mean 同时平均 batch、range 和 azimuth 三个维度。完整基础 loss 为：

1image_per_sample = (
2 sum_hw(abs(X_pred-X_true)**2)
3 / clamp_min(sum_hw(abs(X_true)**2), 1e-8)
4)
5L_image = mean_batch(image_per_sample)
6
7echo_pred = A(X_pred)
8echo_per_sample = (
9 sum_hw(abs(echo_pred-S_observed)**2)
10 / clamp_min(sum_hw(abs(S_observed)**2), 1e-8)
11)
12L_echo_observed = mean_batch(echo_per_sample)
13
14L_total = L_image + echo_weight*L_echo_observed + sparse_weight*L_sparse

Round 1 使用 echo_weight=0.1；Round 2/3 和 Round 12–15 的训练 batch 使用 echo_weight=0.5。sparse_weight 均为 1e-4。

Stage 1 训练完成后保存：

1checkpoint-last.pt
2history.json
3metrics.json
4learned_parameters.csv

2.5 Stage 1 结果定位

当前已验证的 Stage 1 结果：

1Image NMSE ≈ 0.003895
2Clean echo NMSE ≈ 0.00875
3Yak -40~-60 band ≈ 3.18%
4Yak >-60 support ≈ 3.29%
5H20 latency ≈ 1.75 ms

Stage 1 的特点：

参数量极小；

物理约束强；

不直接学习飞机纹理；

不容易记住 synthetic generator；

Yak-42 机体结构保留最好；

没有 Stage 2/3 的全图低幅底噪。

缺点：

所有空间位置共用 scalar schedule；

没有空间自适应阈值；

仍保留一部分 -40~-60 dB 弱响应；

不能显式区分机体弱散射和背景。

3. Stage 2：CNN proximal

Stage 2 在每层 soft-threshold 后加入 CNN proximal。

3.1 ADMM 主体

ADMM 主体仍然是 8 层，更新与 Stage 1 相同：

1D = Z - U
2R = A(D) - S
3X_next = D - c_k Aᴴ(R)
4Z_temp = soft(X_next + U, τ_k)
5Z_next = CNNProx(Z_temp)
6U_next = U + β_k(X_next - Z_next)

3.2 CNN 结构

默认参数：

1channels = 32
2depth = 3

结构：

1Conv2d(2, 32, kernel_size=3, padding=1)
2GELU
3Conv2d(32, 32, kernel_size=3, padding=1)
4GELU
5Conv2d(32, 32, kernel_size=3, padding=1)
6GELU
7Conv2d(32, 2, kernel_size=3, padding=1)

复数 proximal 过程：

1channels = complex_to_channels(values)
2correction_channels = cnn(channels)
3correction = complex_from_channels(correction_channels)
4output = values + tanh(scale) * correction

其中：

1scale 是可学习 scalar
2scale 初始化为 0.1

默认在 8 层之间共享同一个 proximal 模块：

1share_proximal = True

初始化必须保持 PyTorch 构造时行为：所有 Conv2d 的 weight/bias 使用当前 PyTorch 的默认 reset_parameters()，没有额外手工初始化；唯一显式初始化的是 residual scale=0.1。训练入口先执行 torch.manual_seed(seed)，再构造模型。若要尽量复现训练轨迹，应使用相同 PyTorch 版本，不能把 CNN 改成自定义 Xavier/zero initialization。

3.3 失败机制

普通 CNN proximal 的问题：

CNN 的输出不是严格零保持；

对弱输入也可能输出非零 correction；

8 层反复累积后，低幅响应铺满全图；

observed residual 可能更低，但 clean echo 变差；

Yak-42 背景出现大量 -40~-60 dB 响应。

已验证 Yak 结果大约为：

1Yak -40~-60 band ≈ 67%
2Yak >-60 support ≈ 68%

因此 Stage 2 不能作为当前主模型。

4. Stage 3：Transformer proximal

Stage 3 用 Patch Transformer 替换 CNN proximal，ADMM 主体不变。

4.1 Transformer 参数

1patch = 8
2embed_dim = 96
3depth = 2
4heads = 4
5feedforward_dim = 384
6dropout = 0
7activation = GELU
8batch_first = True
9norm_first = True

输入图像尺寸为 (512,128)，patch=8 后：

1512 / 8 = 64
2128 / 8 = 16
3token_count = 64 × 16 = 1024

4.2 结构

1[2,512,128]
2→ Conv2d(2,96,kernel=8,stride=8)
3→ [96,64,16]
4→ flatten + transpose
5→ [1024,96]
6→ 加 learnable positional embedding [1,1024,96]
7→ 2 层 TransformerEncoder
8→ reshape 为 [96,64,16]
9→ ConvTranspose2d(96,2,kernel=8,stride=8)
10→ complex residual correction

显式初始化与构造语义：

1positional embedding = 全零 [1,1024,96]
2residual scale = 0.1
3Conv2d/ConvTranspose2d/Linear = PyTorch 默认初始化
4TransformerEncoder = 从一个 TransformerEncoderLayer clone depth=2

不要为每层单独重新随机创建不同 encoder layer；历史实现把一个已初始化的 layer 传给 nn.TransformerEncoder(layer, depth)。其余默认初始化细节可能随 PyTorch 版本变化，因此训练级复现需要固定框架版本和 model construction 顺序。

输出：

1output = values + tanh(scale) * correction

参数量：

1346,683

注意 346,687 是后续 SupportGatedTransformerProx 版本的参数量，基础 Stage 3 没有额外 gate/output scalar。

4.3 失败机制

Transformer 的长程建模能力没有自动转化为 Yak 结构优势：

更容易拟合 measurement noise；

背景非零 correction 更密集；

延迟高于 CNN；

Yak support 过大，底噪明显。

因此当前项目不建议直接继续扩大 Transformer。

5. SupportFusionADMM

SupportFusionADMM 是对 CNN/Transformer proximal 的零保持和 support gating 改进。

5.1 Support gate

定义：

1threshold = softplus(raw_threshold)
2
3support_gate(v) = |v| / (|v| + threshold + ε)

对于 v=0：

1support_gate(0) = 0

因此 proximal correction：

1correction = proximal(v)
2gate = support_gate(v)
3output = v + tanh(scale) * gate * correction

5.2 SupportGatedCNNProx

结构和普通 CNN proximal 相同：

1Conv2d(2,32,3,padding=1)
2GELU
3Conv2d(32,32,3,padding=1)
4GELU
5Conv2d(32,32,3,padding=1)
6GELU
7Conv2d(32,2,3,padding=1)

但 correction 乘以 support_gate(values)。

5.3 SupportGatedTransformerProx

Transformer 结构保持 Stage 3：

1patch=8
2dim=96
3depth=2
4heads=4

输出 correction 乘以 support gate。

5.4 X/Z 融合

每层完成后，对 sparse 状态做最终清理：

1clean_sparse = soft_threshold(sparse, output_threshold)
2mask = support_gate(clean_sparse, output_gate_threshold)

最后融合：

1mix = sigmoid(raw_output_mix)
2output = clean_sparse + mix * mask * (image - clean_sparse)

默认：

1output_threshold = 0.001
2output_gate_threshold= 0.01
3output_mix = 0.5

5.5 局限

Support gate 只能保证“零输入不会生成 correction”，不能自动识别真实飞机弱散射。它仍可能：

删除弱结构；

支撑过于保守；

在 learned branch 中产生域相关响应。

因此下一步使用 Stage 1 作为 support teacher。

6. GuideSupportFusionADMM

这是当前从 CNN/Transformer 转向 physics-guided support 的关键版本。

6.1 两个 ADMM 分支

模型同时维护两个分支：

Frozen guide branch

使用 Stage 1 checkpoint 中的 scalar schedule：

1guide_raw_c
2 guide_raw_tau
3guide_raw_beta

它们注册为 buffer，不训练。

Guide checkpoint 路径由环境变量：

1GUIDE_CHECKPOINT

传入；默认相对路径为：

1runs/admm_stage1_full_8gpu/checkpoint-last.pt

加载协议只读取 checkpoint 的 model_state，并只复制三个 key：

1raw_c → guide_raw_c
2raw_tau → guide_raw_tau
3raw_beta → guide_raw_beta

每个 shape 必须与当前 num_layers 一致，否则报错。不会复制 Stage 1 的 optimizer、history，也不会复制任何 proximal 权重。三个 guide tensor 注册为 buffer，所以会随新模型 checkpoint 保存和迁移 device，但不计入 trainable parameter。

Learned branch

使用可训练参数：

1raw_c
2raw_tau
3raw_beta

并使用共享 SupportGatedCNNProx 或 SupportGatedTransformerProx。

6.2 Guide branch 更新

guide branch 使用普通 8 层 ADMM：

1guide_image, guide_sparse = unroll(
2 observed,
3 softplus(guide_raw_c),
4 softplus(guide_raw_tau),
5 softplus(guide_raw_beta),
6 proximal=False,
7)

6.3 Learned branch 更新

1learned_image, learned_sparse = unroll(
2 observed,
3 softplus(raw_c),
4 softplus(raw_tau),
5 softplus(raw_beta),
6 proximal=True,
7)

6.4 Firm support

从 guide image 的相对峰值构造 support。

可学习下边界：

1low_db = -65 + 20 × sigmoid(raw_support_db)

默认：

1support_db_init = -55
2support_width_db = 10

因此：

1high_db = low_db + support_width_db

归一化峰值是逐样本、保留空间广播维度计算：

1peak = torch.amax(abs(guide_image), dim=(-2,-1), keepdim=True)
2peak = peak.clamp_min(1e-12)

不是对整个 batch 取一个全局最大值。batch size 大于 1 时，每个样本都有自己的 dB 参考峰值。

转换为幅度阈值：

1low = peak × 10^(low_db/20)
2high = peak × 10^(high_db/20)

firm mask：

1mask = clamp((|guide_image|-low)/(high-low+ε), 0, 1)
2guide_clean = guide_image × mask

6.5 Guide/learned 融合

1mix = sigmoid(raw_mix)
2output = guide_clean + mix × mask × (learned_image-guide_clean)

默认：

1output_mix = 0.5

这一步的物理含义：

Stage 1 决定“哪里可能有结构”；

learned branch 只能在 guide support 中修正；

support 外不能自由生成 CNN/Transformer 响应。

6.6 Support 内 masked data consistency

对每个可学习 step：

1correction = Aᴴ(A(output)-S)
2output = mask × (output - softplus(raw_step) × correction)

support 外被重新乘为零。

原始 Guide 版本：

1dc_steps = 2

这被证明对 support 内幅度求解不够充分。

7. Round 32–36

以下五轮是当前项目最后一组自主迭代。

7.1 Round 32：Guide + 8-step DC

模型：

1GuideSupportFusionADMM
2proximal = CNN
3dc_steps = 8
4support_width_db = 10

训练目标：

1image NMSE
2+ clean echo NMSE
3+ discrepancy
4+ background

关键假设：

Stage 1 support 是对的，问题主要是 support 内的复数幅度没有被充分物理求解。

结果：

1point image NMSE = 0.00690
2point clean echo NMSE = 0.00656
3dense image NMSE = 0.17163
4dense clean echo NMSE = 0.03911
5Yak -40~-60 band = 0.820%
6Yak >-60 support = 1.598%
7Yak entropy = 2.689
8parameter count = 19,718

结论：当前五轮中综合最优。

7.2 Round 33：Soft confidence band

将单一 firm mask 改成三段式 confidence：

1db >= -40： confidence = 1
2-60 < db < -40： confidence = (db + 60) / 20
3db <= -60： confidence = 0

实现形式：

1strong = (db >= -40).float()
2weak = clamp((db + 60) / 20, 0, 1)
3confidence = maximum(strong, weak)

然后：

1output = guide_image + mix × confidence × (learned_image-guide_image)

使用 4 步 masked DC。

结果：

1point image NMSE = 0.00428
2point clean echo NMSE = 0.00406
3dense image NMSE = 0.23157
4Yak -40~-60 band = 0.988%
5Yak >-60 support = 1.532%
6Yak entropy = 3.184

结论：结构和背景仍然安全，但 dense 泛化劣于 Round 32。

7.3 Round 34：Stage-1 residual refinement

模型输出：

1x_final = x_stage1 + mask_teacher × residual_cnn(x_stage1)

Residual CNN：

1Conv2d(2,32,3,padding=1)
2GELU
3Conv2d(32,32,3,padding=1)
4GELU
5Conv2d(32,2,3,padding=1)

scale 初始化：

10.05

结果：

1point image NMSE = 0.01234
2dense image NMSE = 0.39823
3Yak -40~-60 band = 31.753%
4Yak >-60 support = 32.211%

失败原因：

teacher mask 是连续 mask，不是严格二值 support；

residual CNN 在弱 support 上生成密集低幅 correction；

Yak 图中大量响应是底噪，不是真实飞机结构。

该方案不能直接作为主模型。

7.4 Round 35：Support + explicit physics solve

初始：

1output = guide_image × guide_mask

之后执行 8 次：

1residual = A(output) - observed
2output = mask × (
3 output - softplus(raw_step[k]) × Aᴴ(residual)
4)

模型只学习 8 个物理 step size，不让 CNN 直接自由生成最终图像。

结果：

1point image NMSE = 0.00128
2point clean echo NMSE = 0.00113
3dense image NMSE = 0.69036
4Yak -40~-60 band = 0.103%
5Yak >-60 support = 0.256%

结论：point-only 物理求解非常强，但 support 太硬，删除 Yak 弱结构，严重过稀疏。

7.5 Round 36：多域混合 + support distillation

训练数据混合：

1point-only
2structured aircraft
3 dense aircraft

默认：

1structured_probability = 0.75

模型使用 Round 33 的 confidence support。

loss 中增加弱 support energy 约束：

1support_energy = sum(|prediction|² × protected) / target_energy
2support_loss = mean(relu(0.05 - support_energy))

总 loss：

1image
2+ 0.5 × clean_echo
3+ 0.1 × discrepancy
4+ 0.2 × background
5+ 0.1 × support_loss

结果：

1point image NMSE = 0.00631
2point clean echo NMSE = 0.00593
3dense image NMSE = 0.18635
4Yak -40~-60 band = 1.087%
5Yak >-60 support = 1.565%
6Yak entropy = 3.554

结论：dense 泛化改善，但 Yak support 没有超过 Round 32；当前 support distillation 仍然太弱。

8. 数据集复刻

8.1 Point-only synthetic

每个样本使用：

1rng = numpy.random.default_rng(seed + index)

生成稀疏复数 scatterer：

随机位置；

随机幅度；

随机相位；

峰值归一化；

使用同一个 forward operator 生成 clean echo；

snr ~ Uniform(-10,30)；

加复数 Gaussian noise。

噪声标准差：

1power = mean(|clean|²)
2std = sqrt(power / 10^(snr/10) / 2)
3noise = std × (N(0,1) + iN(0,1))

Point-only 的离散采样必须按下面的 NumPy 语义复刻：

1count = int(rng.integers(3, 30 + 1)) # 3 和 30 都可能取到
2rows = rng.integers(0, P, size=count) # 0 <= row < P
3cols = rng.integers(0, Q, size=count) # 0 <= col < Q
4amplitude = rng.uniform(0.5, 1.0, count)
5phase = rng.uniform(-pi, pi, count)

位置在全图整数网格上均匀采样。多个 scatterer 可以落在同一像素，复数值用 += 相加，随后才按全图峰值归一化。

非缓存历史任务使用：

1rng = np.random.default_rng(dataset_seed + index)

如果 cache=True，历史实现不是逐 index 重置 RNG，而是创建一次 default_rng(dataset_seed) 后顺序生成整个数据集。因此 cache 与 no-cache 在相同 dataset seed 下并不保证逐样本相同。正式 Round 1–36 的相关启动脚本使用 --no-cache 或 dataset 内部 cache=False，复刻历史结果应使用逐 index RNG。

混合数据集每个 index 的顺序是：

1rng = default_rng(seed + index)
2is_structured_or_dense = rng.random() < probability

如果该样本落入 point branch，传给 point generator 的是已经消耗过一次 rng.random() 的同一个 RNG。因此 mixed dataset 中的 point 样本不等于纯 SyntheticISARDataset 在相同 seed/index 下的样本。

8.2 Structured aircraft v1

目标中包含：

一条机身线段；

一条主翼线段；

一条尾翼线段；

两个 engine/hub cluster；

随机缺失点；

坐标抖动；

随机幅度和相位。

默认结构参数范围：

1center row ∈ [0.4P, 0.6P]
2center col ∈ [0.4Q, 0.6Q]
3angle ∈ [-0.35,0.35]
4body length ∈ [0.14P,0.27P]
5wing span ∈ [0.18Q,0.38Q]

两个 hub 的精确中心为：

1hub(sign) = center - 0.05*length*axis + sign*0.23*span*wing
2sign in {-1,+1}

每个 hub 追加 5 个点，每点坐标噪声为 Normal(0,[2.0,1.0])。hub 和三条线段的点最终统一进入同一个 coords 列表，因此它们使用相同的：

1amplitude ~ Uniform(0.35,1.0)
2phase ~ Uniform(-π,π)
3round-to-nearest integer pixel
4out-of-bounds point 丢弃

Structured-v1 的 RNG 调用顺序也属于逐样本复刻的一部分：

11. 先抽 domain Bernoulli；
22. 抽 center、angle、length、span；
33. 依次遍历 body/main-wing/tail 的 linspace 点，逐点抽删除 Bernoulli；
44. 未删除点立刻抽 coordinate jitter，坐标追加到 coords；
55. 依次为左右 hub 各抽 5 次 jitter，追加到 coords；
66. 所有坐标收集完后，才按 coords 顺序逐点抽 amplitude 和 phase；
77. 峰值归一化；生成 clean echo；抽 SNR；最后抽复 Gaussian noise。

如果在生成坐标时就同时抽幅度/相位，会改变后续 RNG 流，从而无法逐样本一致。

8.3 Dense aircraft v2

Dense v2 解决 v1 只有离散点的问题：

机身、主翼、尾翼是连续散射带；

每个散射点使用 Gaussian splat；

结构带具有厚度；

amplitude 沿结构 taper；

phase 具有 global phase 和 phase slope；

保留 nose、tail、engine、wing-tip landmarks；

支撑规模约 2.83%。

默认：

1body count = 100
2wing count = 70
3tail count = 36
4structured probability = 0.5 或 0.75

Dense v2 的六个 landmark 不是模糊的“nose/tail/engine/wing-tip”，其精确相对坐标为：

1nose = center - 0.49*length*axis
2tail = center + 0.49*length*axis
3
4inner_left = center - 0.07*length*axis - 0.25*span*wing
5inner_right = center - 0.07*length*axis + 0.25*span*wing
6wingtip_left = center - 0.07*length*axis - 0.49*span*wing
7wingtip_right = center - 0.07*length*axis + 0.49*span*wing

每个 landmark 在 splat 前再加：

1coordinate jitter ~ Normal(0,[0.5,0.3])
2amplitude ~ Uniform(0.55,1.0)
3phase = global_phase + Normal(0,0.35)
4Gaussian sigma = (1.15,0.85)

Dense 三条结构带的完整端点为：

1body_start = center - 0.50*length*axis
2body_end = center + 0.50*length*axis
3
4wing_center = center - 0.07*length*axis
5wing_start = wing_center - 0.50*span*wing
6wing_end = wing_center + 0.50*span*wing
7
8tail_center = center + 0.38*length*axis
9tail_start = tail_center - 0.24*span*wing
10tail_end = tail_center + 0.24*span*wing

9.1.1 AMP、GradScaler 和数值环境

所有正式 CUDA 训练的 train batch 都在：

1torch.autocast("cuda", dtype=torch.bfloat16)

中执行 forward 和 loss，并同时使用：

1torch.amp.GradScaler("cuda")

代码没有覆盖 GradScaler 构造参数，因此当前 PyTorch 默认是：

1init_scale = 65536
2growth_factor = 2.0
3backoff_factor = 0.5
4growth_interval = 2000

发生 non-finite gradient 时 scaler 可以跳过 optimizer step，并降低 scale；因此即使 bf16 通常不依赖 scaling，历史轨迹仍包含 GradScaler 状态。base/support checkpoint 保存 scaler_state，Round 32–36 checkpoint 不保存 scaler state。

validation 和 test 都在 torch.no_grad() 下运行，但不进入 autocast，因此走默认 fp32/complex64 路径。complex_from_channels 不接受 float16/bfloat16 作为 torch.complex 分量；若输入不是 float32/float64，会先执行 values.float()，所以 CNN/Transformer 可以在 bf16 中计算，而进入 FFT/complex 边界时提升到 float32/complex64。

确定性相关实际行为：

1base trainer 和 support trainer：CUDA 时 cudnn.benchmark=True
2Round 32–36 trainer：没有设置 cudnn.benchmark
3所有 trainer：未启用 torch.use_deterministic_algorithms(True)
4正式大多数 run 脚本：OMP_NUM_THREADS=1, NCCL_DEBUG=WARN
5Dense-v2 pilot shell：没有显式设置 OMP_NUM_THREADS

所以不能笼统声称全部脚本数值环境完全一致。训练级复现应保存 PyTorch/CUDA/cuDNN 版本、GPU 型号、GradScaler state，并按对应脚本族恢复环境。

9.2 Noise-aware loss

给定预测图像 X_pred、目标图像 X_true 和 observed measurement S：

1S_clean = A(X_true)
2S_pred = A(X_pred)

image loss：

1L_image = ||X_pred-X_true||² / (||X_true||²+ε)

clean echo loss：

1L_clean_echo = ||S_pred-S_clean||² / (||S_clean||²+ε)

observed residual 只记录，不单独作为唯一优化目标：

1L_observed = ||S_pred-S||² / (||S||²+ε)

discrepancy：

1noise_true = ||S-S_clean||² / ||S||²
2residual_pred = ||S_pred-S||² / ||S||²
3L_discrepancy = (residual_pred-noise_true)²

background loss：

根据目标非零位置建立 support；

用 3×3 max-pool 保护目标邻域；

其余区域作为 background；

对 background 的预测幅度施加 L1+L2 惩罚。

最终：

1L_total = L_image
2 + 0.5 × L_clean_echo
3 + 0.1 × L_discrepancy
4 + 0.2 × L_background
5 + optional 0.1 × L_support

9.3 Checkpoint selector

每轮保存：

1checkpoint-best.pt
2checkpoint-last.pt
3history.json
4metrics.json

Round 32–36 使用：

1score = validation_total + 0.5 × validation_background

不能选择：

1observed residual 最低的 checkpoint

因为这可能等价于选择“拟合最多噪声”的模型。

基础训练器 Round 1–3、12–15 的 checkpoint-best.pt 判据是：

1current_validation = validation["total"]
2if current_validation < best_validation:
3 save("checkpoint-best.pt")

但必须保留一个历史实现细节：validation 通过 run_epoch(..., optimizer=None) 调用 compute_loss，没有把命令行的 echo_weight 和 sparse_weight 继续传入，因此 validation 使用函数默认值：

1validation echo_weight = 0.1
2validation sparse_weight = 1e-4

所以：

1R1：train echo=.1，validation echo=.1，一致
2R2/R3：train echo=.5，validation echo=.1，不一致
3R12–R15：train echo=.5，validation echo=.1，不一致

这不是推荐设计，而是已经完成实验的真实 selector 行为。为了复刻现有 checkpoint-best.pt 必须保留；若修复为 validation 也使用 .5，应作为新实验而不是历史复刻。

Round 4–7 的 background 精确为纯 L2：

1support = (abs(target) > 1e-6).float()[:,None]
2protected = max_pool2d(support, 3, 1, 1)[:,0]
3bg = 1-protected
4L_bg_energy = mean_batch(
5 sum_hw(abs(prediction)**2 * bg)
6 / clamp_min(sum_hw(abs(target)**2), 1e-8)
7)

Round 8–11、16–31 的 background 为：

1L_bg_l2 = L_bg_energy
2rms = sqrt(mean_hw(abs(target)**2)).clamp_min(1e-8)
3L_bg_l1 = mean_batch(mean_hw(abs(prediction)*bg) / rms)
4L_background = L_bg_l2 + L_bg_l1

它与 Round 32–36 的 background 数学定义相同；差异只在总 loss 中的权重。

10.1 Yak42.mat 的精确预处理

这是复现 Yak 数字最关键的一段。MAT 文件必须包含二维复数变量 y，且 azimuth 列数至少为 192。处理顺序如下：

1raw = scipy.io.loadmat(path)["y"].astype(np.complex128)
2selected = np.array(raw[:, 128:192], copy=True) # MATLAB 129:192
3selected /= np.max(np.abs(selected))

只截取 azimuth 列，不裁剪 range 行。当前文件截取后尺寸为 (256,64)。

添加固定复数噪声：

1NOISE_STD = 0.505 * 0.03 * sqrt(2.0) # 约 0.021425
2rng = np.random.default_rng(seed)
3noise = NOISE_STD * (
4 rng.standard_normal(selected.shape)
5 + 1j*rng.standard_normal(selected.shape)
6)
7noisy = selected + noise

注意 NOISE_STD 分别乘 real 和 imaginary 标准正态，因此复噪声总功率包含两个分量。报告 SNR 的历史计算为：

1noise_variance = np.var(noise, ddof=1)
2signal_energy = np.linalg.norm(selected)**2
3snr_db = 10*log10(signal_energy / (noise_variance*selected.size))

最后在 axis 0 做 IFFT：

1measurements = np.fft.ifft(noisy, axis=0).astype(np.complex128)

这里不做 fftshift，不再 peak-normalize，也不先通过 synthetic forward operator。得到的 measurements 才是传统 ADMM 和网络共同使用的 (256,64) 输入。送入网络前转换为 complex64，再堆成 [1,2,256,64] 的 real/imag channels。

历史 31 轮总览固定 seed=0。Round 32–36 聚合评测对 seed 0,1,...,9 分别完整重复上述“重新生成噪声 + IFFT”流程。

10.2 Entropy 的精确定义

这里的 entropy 不是直方图熵，也没有除以 log(PQ)。它是图像能量形成的离散概率分布的自然对数 Shannon entropy：

1power = abs(image)**2
2total = power.sum()
3if total == 0:
4 entropy = 0.0
5else:
6 probability = power[power > 0] / total
7 entropy = -(probability * np.log(probability)).sum()

因此文档其他位置的“normalized image entropy”应理解为“按总能量归一化概率后计算的 entropy”，不是归一到 [0,1] 的 entropy。

10.3 Fast-ADMM-40 的精确参数和更新

基线调用：

1admm_2d_fast(
2 measurements,
3 image_shape=(512,128),
4 tol=1e-5,
5 alpha=0.0065,
6 delta=1.0,
7 max_iterations=40,
8)

初始化：

1X0 = A_H(S)
2Z0 = zeros_like(X0)
3U0 = zeros_like(X0)

第 k 次更新：

1D = Z-U
2X_next = D - A_H(A(D)-S)/(delta+1)
3Z_next = complex_soft_threshold(X_next+U, alpha/delta)
4U_next = U + X_next-Z_next
5relative_change = norm(X_next-X) / norm(X)

若旧 X 的 norm 为 0：change 也为 0 时 relative change=0，否则为 inf。每步先保存最新 X/Z/U，再检查 relative_change <= 1e-5；因此“Fast-ADMM-40”是最多 40 步，可能提前停止。返回和画图的是 X，不是 Z。

基础 synthetic selector 使用的固定 Fast-ADMM reference 为：

1image_nmse = 0.4275802185509148
2echo_nmse = 0.11309962187112717
3image_entropy= 4.142121178538367
4iterations = 40

1c_init = 1/(1+delta) = 0.5
2tau_init = alpha/delta = 0.0065
3beta_init = 1.0

所以 Stage 1 不是任意选择三个初值，而是把 Fast-ADMM 的固定更新系数展开为逐层可学习 schedule。若所有层保持初始化不训练，其更新形式与该经典基线的对应系数一致；差别还包括固定迭代数/早停和网络固定返回第 L 层 X_L。

13. 复刻验收标准

另一个实现满足以下条件才算结构复刻成功：

Stage 1 为 8 层 ADMM unfolding；

每层拥有正值 c/tau/beta；

Stage 2 CNN 结构为 2→32→32→32→2，3×3 convolution，GELU；

Stage 3 Transformer 为 patch=8、dim=96、2 层、4 heads；

Guide branch 使用冻结 Stage 1 schedule；

Round 32 使用 8 个 support-masked DC steps；

Round 33 使用 >-40、-40~-60、<-60 三段 confidence；

Round 34 使用 Stage 1 residual CNN；

Round 35 使用 8 个显式 physics solve step；

Round 36 使用 point/dense 混合训练；

loss 包含 clean echo 和 discrepancy，而不是只优化 noisy observed echo；

输入输出形状和复数通道约定一致；

[-60,0] dB 可视化流程一致；

能解释 Round 34 底噪泄漏和 Round 35 过度稀疏的原因。

不能保证逐参数相同；

24.3 如何从表中复现八张图的结论

1Group 01：CNN/Transformer 降低 observed residual，但 Yak 底噪扩大到 69%–76%。
2Group 02：zero-preserving 有效但不稳定，可能仍稠密，也可能过度稀疏。
3Group 03：Stage 1 guide 把 band 降到约 0.5%，但 support 低于 Stage 1。
4Group 04：深层 scalar + echo=.5 导致 80% 以上底噪。
5Group 05：echo weight 从 .15 到 .45 时，底噪单调增加。
6Group 06：clean echo loss 在 synthetic 上成功，但 Yak 只剩强点。
7Group 07：离散飞机轮廓没有解决真实弱结构迁移。
8Group 08：连续 dense target 仍没有解决 Yak domain gap。

29.3 为什么同一网络可能在两张图里“看起来差很多”

复刻时必须同时固定以下因素，否则不能认为是同一结果：

dB 窗口；[-40,0] 会隐藏大量 -40~-60 dB 底噪，[-60,0] 会暴露它。

checkpoint；last、best-image、best-score、best-constrained 可能视觉差异很大。

Yak seed 和噪声 realization；历史总览固定 seed 0。

是否对输出再次裁剪、threshold 或按 support mask 后处理。

FFT shift、axis 顺序、origin 和 extent。

是否对每张图独立按峰值归一化。

因此，判断“Stage 1 比 Stage 2/3 背景干净”时，应使用同一个 [-60,0] dB、同一 seed、同一 peak normalization；按这一口径，R1 band=3.0991%，R2=68.8995%，R3=75.0259%。

30. Round 32–36 可直接照写的训练 loss 与 selector

30.1 张量定义

1pred = complex_from_channels(pred_ch) # [B,512,128]
2tgt = complex_from_channels(target_ch) # [B,512,128]
3obs = complex_from_channels(measurement) # [B,256,64]
4clean = A(tgt)
5pred_echo = A(pred)

批内 NMSE 采用“先逐样本空间求和，再对 batch 求均值”：

1def nmse(a, b):
2 per_sample = sum_hw(abs(a-b)**2) / clamp_min(sum_hw(abs(b)**2), 1e-8)
3 return mean_batch(per_sample)

30.2 五个基础项

1image = NMSE(pred, tgt)
2clean_echo = NMSE(pred_echo, clean)
3observed_residual = NMSE(pred_echo, obs) # 只报告，不直接进入 total
4
5obs_energy = sum_hw(abs(obs)**2).clamp_min(1e-8)
6true_noise_ratio = sum_hw(abs(obs-clean)**2) / obs_energy
7predicted_noise_ratio = sum_hw(abs(pred_echo-obs)**2) / obs_energy
8discrepancy = mean((predicted_noise_ratio - true_noise_ratio)**2)

protected background mask：

1support = (abs(tgt) > 1e-6).float()[:, None]
2protected = max_pool2d(support, kernel_size=3, stride=1, padding=1)[:, 0]
3bg = 1 - protected
4target_energy = sum_hw(abs(tgt)**2).clamp_min(1e-8)
5target_rms = sqrt(mean_hw(abs(tgt)**2)).clamp_min(1e-8)
6background = mean_batch(sum_hw(abs(pred)**2 * bg) / target_energy) \
7 + mean_batch(mean_hw(abs(pred) * bg) / target_rms)

Round 33/36 的 support hinge：

1support_energy = sum_hw(abs(pred)**2 * protected) / target_energy
2support_loss = mean(relu(0.05 - support_energy))

Round 32/34/35 令 support_loss=0。

最终：

1total = image \
2 + 0.5 * clean_echo \
3 + 0.1 * discrepancy \
4 + 0.2 * background \
5 + 0.1 * support_loss

这里有一个重要历史现象：Round 33/36 的 support_loss 在最终测试表里为 0，表示预测的 protected-region energy 已越过 0.05 下限，hinge 不再提供梯度。Round 36 的 improvement 主要来自更高 dense 比例，而不是强 support distillation。

30.3 Selector 精确实现

每个 epoch 完成 rank-0 validation 后：

1score = validation["total"] + 0.5 * validation["background"]
2if score < best:
3 save checkpoint-best.pt
4always save checkpoint-last.pt

训练结束必须重新加载 checkpoint-best.pt，再对 test set 计算 metrics.json。因此 Round 32–36 的表中 test 结果不是 last epoch 未选择权重。

31. Round 32–36 forward 的逐行语义规范

前面第 7 节给出了公式；本节补充容易写错的实现语义。

31.1 Round 32

1父类 = GuideSupportFusionADMM
2learned proximal = CNN
3num_layers = 8
4guide = frozen Stage 1 scalar-8 schedule
5dc_steps = 8
6support_db_init = -55
7support_width_db = 10
8output_mix init = 0.5

父类先计算 guide branch 和 learned branch，再用 firm support 融合，最后进行 8 次 masked data consistency。每个 DC step 有一个独立 raw scalar，正步长为 softplus(raw_step)。输出每一步后不做额外 soft-threshold。

参数量 19,718 的组成关系：

1Guide CNN baseline 19,712

3总计 19,718

31.2 Round 33

先分别运行冻结 guide 和 learned CNN ADMM branch。由 guide_image 的相对峰值 dB 构造 confidence。峰值同样逐样本计算：

1peak = torch.amax(abs(guide_image), dim=(-2,-1), keepdim=True).clamp_min(1e-12)
2db = 20*log10(abs(guide_image)/peak + 1e-12)
3strong = 1(db >= -40)
4weak = clamp((db + 60)/20, 0, 1)
5confidence = maximum(strong, weak)

这个写法等价于：

1db < -60 → 0
2-60<=db<-40 → 线性 0→1
3db>=-40 → 1

融合：

1output = guide_image + sigmoid(raw_mix) * confidence * (learned_image-guide_image)

4 次 DC：

1correction = A_H(A(output)-observed)
2output = confidence * (output-softplus(raw_step)*correction)

注意乘 confidence 的位置在整个更新之后；这会让 confidence=0 的区域每一步严格归零。

评估中看到的“多 2 个 scalar”来自父 guide 明确以 dc_steps=4 构造，而常用 Guide baseline 参数量 19,712 是 dc_steps=2。R34 最终 forward 虽不使用 states.output，父模块的 4 个 raw_dc_steps 仍注册为参数并计入总参数量；这也是 DDP 需要 find_unused_parameters=True 的原因之一。

31.4 Round 35

父 guide 模块仍被构建并计算 states，但最终 solver 从：

1output = guide_image * guide_mask

开始，随后执行 8 次：

1residual = A(output)-observed
2output = guide_mask * (output-softplus(raw_step)*A_H(residual))

raw_steps 是形状 [8] 的 Parameter，全部初始化为 -2.0。guide mask 每步重新相乘，因此 mask 外永远严格为 0。这解释了 point-only 极好而 Yak 极度稀疏。

31.5 Round 36

网络类直接继承 Round 33，forward 完全相同。Round 36 与 Round 33 的网络结构和参数量均相同；差异仅为：

1dense probability: 0.50 → 0.75
2独立重新训练
3model_config round_variant 名称不同

不要额外添加一个 distillation head；历史实现中的 distillation 只存在于 loss 的 support-energy hinge。

32.3 精确复现的三个等级

必须对“复刻”做严格区分：

A. 架构级复刻

只依赖本文档即可完成：模块、tensor shape、forward 顺序、参数量、loss、数据分布和 selector 应全部一致。

B. 训练级复刻

使用相同代码、seed、数据 RNG、GPU 数、PyTorch/CUDA/cuDNN 版本和 checkpoint selector，可复现相同趋势和接近的数值。DDP reduction、FFT kernel 和 AMP 可能导致小幅数值差异。

C. 权重/逐像素级复刻

CNN/Transformer 有数万到数十万学习权重，Markdown 没有逐项嵌入这些浮点数；没有原始 checkpoint 时不可能从结果表反推出完全相同的权重。因此本文档保证的是 A，并尽量支持 B；若要求 C，必须另行复制对应 .pt checkpoint。Section 25 中列出的 scalar schedule 是例外，它足以恢复那些 scalar-only 模型的主要 learned forward 参数。

另一个对话不应声称“仅凭文档可逐 bit 恢复 R2–R36 的所有已训练神经网络权重”。正确的验收口径是结构、参数量、训练行为、趋势和指标范围。

33.4 结果趋势的硬验收区间

考虑训练非确定性，可用以下宽松区间判断实现是否发生结构性错误：

1R1 Yak band 应为个位百分比，而不是 50% 以上。
2R2/R3 Yak band 应明显高于 R1，历史值约 69%/75%。
3R8–R11 Yak support 应约 0.5%–2%，不应出现全图稠密。
4R12–R15 Yak band 应非常高，历史值约 80%–85%。
5R16→R19 Yak band 应随 observed echo weight 总体单调增加。
6R20–R31 Yak support 应极低，通常低于 0.1%。
7R32 Yak band 应约 0.5%–1.5%，support 约 1%–2.5%。
8R34 Yak band 若仍约 30%，说明正确复现了 residual leakage 失败机制。
9R35 point image 应显著优于 dense image，且 Yak support 远低于 1%。
10R36 应接近 R33，但 dense 泛化优于 R33；不应被实现成新 head。

若完全相反，依次检查：

1complex channel 顺序 → FFT shift → A/A_H normalization → support dB normalization
2→ mask 乘法位置 → echo target 是 clean 还是 observed → selector → 可视化 dB 窗口

37.2 三个路径变量的真实关系

推荐在运行任何训练/评测前统一设置：

1export REPO_ROOT=<WORKSPACE_ROOT>/ADMM
2export RUN_ROOT=<WORKSPACE_ROOT>/runs

4export GUIDE_CHECKPOINT="$RUN_ROOT/admm_stage1_full_8gpu/checkpoint-last.pt"

1RUN_ROOT:
2 Stage 1/2/3 full run shell 的输出根；

4
5ADMM_WORKSPACE:
6 统一可视化脚本的 ROOT；脚本随后读取 ROOT/runs 和 ROOT/ADMM/Yak42.mat。
7
8GUIDE_CHECKPOINT:
9 GuideSupportFusion 和 Round 32–36 的 Stage 1 teacher 文件。

默认行为并不完全统一：

1run_admm_* shell:
2 RUN_ROOT 未设置时默认 <REPO_ROOT>/runs，和历史 <WORKSPACE_ROOT>/runs 不同。
3

5 多数要求调用方直接提供 OUTPUT_DIR；guide 路径仍由 RUN_ROOT 或 GUIDE_CHECKPOINT 决定。

7generate_*visualizations.py:
